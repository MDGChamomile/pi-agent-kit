# simplykst 검증 기록

## 2026-09-15 — v2.1

### 오프라인 검증

`python3 -B -m unittest discover -s tests -v`를 스킬 디렉터리에서 실행합니다. 17개 테스트가 통과했습니다. 산술·결측·상한 우선순위·신뢰도 경계·업종 및 혼합 가중치·문서 표 일치·다른 작업 디렉터리에서의 CLI·오류·합성 입력 예시를 검사합니다. CI에도 같은 명령을 등록했습니다. 실제 공시의 품질이나 투자 성과는 검증하지 않습니다.

### 입력 검증·회귀 테스트 보완

후속 보완에서는 관점·팩터 객체의 알 수 없는 필드와 모든 깊이의 JSON 중복 키를 거부하도록 했습니다. 위험 필드 오타·위험 목록을 덮는 중복 키·이스케이프된 중복 키·결측 팩터의 알 수 없는 필드가 오류로 종료되는지 검사합니다. 오류 메시지에는 입력 키나 값을 노출하지 않습니다.

전체 23개 테스트가 통과했습니다. 서로 다른 팩터 점수와 0점/비영점 팩터 결측의 고정 기대값을 두 관점에서 검증합니다. 별도 임시 사본에서 관측 가중평균을 단순평균으로 바꾸자 해당 두 테스트의 6개 하위 사례가 모두 실패했습니다. 실제 소스의 산식은 변경하지 않았습니다. 기여점수 개별 반올림에 따른 3.51 대 3.50 표시 차이는 테스트로 고정하고 보고서 표에 설명하도록 했습니다. 이 결과는 로컬 오프라인 검증이며 새로운 실기업 완주나 원격 CI 실행을 의미하지 않습니다.

### 보고서 배치 개선 — 합성 사례 점검

[출력 배치 비교](../examples/report-layout.md)에 동일 입력의 전후 발췌를 남겼습니다. 정상 두 관점, 결측·잠정·상한 및 다른 관점 보류, Investing 단일 관점의 세 사례를 기존 계산기로 대조했습니다. 점수·상태·근거 신뢰도·평가 범위·상한 전후 점수 범위와 기여점수가 일치했습니다. 수동 검토에서는 단위·기간·연결 기준·자료 구분·출처 ID와 중요 보류 사유가 유지되는지 확인했습니다. Markdown 상대 링크 검사와 기존 23개 테스트도 통과했습니다. 계산 코드·업종 가중치·조사 기준은 바꾸지 않았습니다.

가설은 결론·가격·판단 변경 조건을 팩터보다 먼저 배치하고 표를 4열로 줄이면 핵심 판단을 찾기 쉬워진다는 것입니다. 반면 상세로의 이동은 검증을 위한 왕복 읽기를 늘릴 수 있습니다. 이번 점검은 합성 발췌의 정보 보존 확인이며 실제 완성 보고서·렌더링 환경별 가독성·독자 읽기 시간·모델의 지침 준수율을 검증하지 않았습니다. 다음 실기업 완주 보고서 검토 시 같은 근거의 전후 본문을 비교하고, 핵심 정보 누락이나 중복 증가가 나타나면 분리 수준을 줄이거나 배치를 되돌립니다. 실사례 검증이 끝났다는 주장은 하지 않습니다.

### 문체 개선 — 의미 보존 점검

`SKILL.md`에 금융 보고서용 문체 원칙과 두 쌍의 예시를 추가했습니다. 수동 대조에서 CB 예시는 ‘해소 여부 미확인 → 평가 보류’를 유지하며 실제 잔존 위험을 단정하지 않았고, 자사주 예시는 ‘계획에 대한 긍정적 평가 + 집행 미확인’을 유지하며 완료 사실로 바꾸지 않았습니다. 두 예시는 수치·시점·인과관계를 새로 추가하지 않습니다. 제목·상태·수치 셀까지 완결문으로 늘리지는 않습니다.

가설은 필요한 조사·서술어와 명확한 금융용어가 독자의 관계 추론 부담을 줄인다는 것입니다. 문장 길이가 늘어날 수 있으므로 다음 실기업 완주 보고서 검토 때 배치 개선과 함께 확인합니다. 의미 변형이나 불필요한 장문화가 발견되면 예시·규칙을 조정하거나 축소합니다. 실제 모델 출력의 교정 성공률을 측정한 결과는 아니며 별도 플러그인·교정 에이전트·반복 재작성 절차를 도입하지 않았습니다.

### 공개 자료 접근 스모크 — 부분 완료

대형주와 적자 바이오 후보를 대상으로 DART 우선 조회와 브라우저/KIND 대체 경로를 시험했습니다. 다음은 투자 분석 결과가 아니라 접근 확인 기록입니다. 검색 요약의 실적 숫자는 원문 확인을 마치지 않아 채택하지 않았습니다.

|---|---|---|---|
| 삼성전자 | [DART 20260310002820](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260310002820) | 일반 웹 추출 실패 후 브라우저에서 2026-03-10 사업보고서 표지, 2025 사업연도, 연결 주석 12 차입금·16 우발부채와 약정사항의 목차 확인 | 주석 선택 직후 스냅샷에는 기존 표지가 남아 본문 갱신 확인 필요. 최신 분기·후속 공시와 정정 전체 점검 미완료 |

제한된 검색 조사에서는 도구 예산이 소진됐으며, 이후 브라우저 확인으로 접근 자체는 가능함을 확인했습니다. 따라서 DART 자체가 접근 불가능하다고 결론내리지 않습니다. 완성된 두 종목 보고서·점수 입력 원장·모형 비교는 아직 없고 **end-to-end 검증 통과가 아닙니다**. 최신성과 시장 시계열·핵심 주석 검토가 미완료여서 실제 추천도를 생성하지 않았습니다. API 키·설치 변경 없이 수행했습니다.

### 다음 검증과 제거 기준

- 대형주와 자료가 부족한 적자기업 각각에 대해 최신 공시·주석·시장 원자료 → 증거 원장 → 요청 관점의 팩터 → 계산기 → 보고서까지 완료하고 원장/입력과 공개 출처를 보존합니다. 보류도 근거와 재현 가능한 입력이 있으면 유효한 결과입니다.
- 같은 증거로 업종 가중치 대 일반 경로, 거래대금 밴드 대 정성 체결 가능성 평가를 비교합니다. 차이가 경제적 설명을 개선하는지, 임의 경계 때문에 결론만 달라지는지 기록합니다. 재현 가능한 순효과가 없으면 해당 특례를 축소·제거합니다.
- 참조 문서 전체 읽기는 유지합니다. 완주 사례에서 실제 읽기 비용과 통제 누락을 측정한 후 필요한 절만 읽는 대안과 비교합니다. 더 짧다는 이유만으로 필수 회계·결측·보안 통제를 빼지 않습니다.
- 재검토 기한: 두 완주 사례가 확보되는 시점 또는 다음 방법론 변경 전 중 먼저 오는 시점. 이는 사용성 검증이며 두 사례로 예측력이나 초과수익을 주장하지 않습니다.
