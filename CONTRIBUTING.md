# Contributing

1. Open an issue for substantial additions or behavior changes.
2. Keep each skill or extension self-contained and portable.
3. Document purpose, invocation, side effects, and platform assumptions.
4. Do not include credentials, private data, absolute machine paths, or generated dependencies.
5. Validate skills and exercise extensions through Pi before submitting a pull request.

By contributing, you agree that your contribution is licensed under the repository's MIT License.
